# Paso 1 – Ubicar el código y arrancar StockPascual

## Objetivo

Ubicar el código del MVP StockPascual, ejecutar la aplicación localmente y realizar un recorrido inicial por sus funcionalidades y roles.

## Entorno utilizado

- Equipo: MacBook Pro M1 Pro.
- Sistema operativo: macOS.
- Node.js: versión 26.
- Navegador: Brave.
- Aplicación: StockPascual.
- URL local: http://localhost:3080

## Arranque de la aplicación

Se ingresó a la carpeta `app` del proyecto y se ejecutaron los comandos necesarios para instalar las dependencias y arrancar la aplicación:

```bash
cd app
npm install
npm start
